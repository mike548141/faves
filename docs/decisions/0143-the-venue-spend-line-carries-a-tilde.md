## Decision (the owner's ruling)

The restaurant page's typical spend reads **`$$ ~$16 per person`** — owner,
2026-09-29: *"I would like a ~ on it so it looks like this '$$ ~$16 per
person'"*. 0141 had made it a bare `$$ $16 per person` earlier the same day.

Still no words: no "about", no "· our estimate". The "~" is the Cook at Home
row's pattern from 0141 — `aria-hidden`, with a visually-hidden "about "
beside it, because "~" alone is spoken as "tilde" or skipped.

bare figure. If it should match, that is a separate call for the owner.
