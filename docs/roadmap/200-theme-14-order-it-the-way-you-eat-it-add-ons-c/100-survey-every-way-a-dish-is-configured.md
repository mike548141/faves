  `200/110`–`200/140`: *"scan all the menus, dishes, and recipes we have and
  look at all the use cases we have for addons / optional extras / dish

  **Why this comes first.** The rulings below describe four mechanisms: a
  default, a must-see flag, a sheet warning, and count rules. None of them
  can be sized until we know how often each shape occurs, whether it is already
  structured or is still prose, and whether the menu's own words say *must*
  or *may*. This item measures that before anyone builds.

  **Method.** Every venue file under `site/data/restaurants/` (56 venues and
  the Cook at Home recipes) dumped one line per dish, with its add-on groups,
  section notes and venue notes. Each line was read, never keyword-counted.
