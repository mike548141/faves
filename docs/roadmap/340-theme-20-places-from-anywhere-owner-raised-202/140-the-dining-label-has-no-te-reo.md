- ⏳ **The "Dining" filter has no te reo, and the gloss on it is knowingly
  wrong** `[S][reo]` — waiting on a fluent speaker, not on a session. Arrived
  2026-08-17 with the owner's wording ruling (`010/010`).

  **The state, said plainly because the file says it too.** The label reads
  **"Dining" / "All dining"**. The gloss still reads **`Ratonga`** (*service*)
  and **`Ngā ratonga katoa`**. The two languages now name different things on
  the same control. That is recorded in `site/js/reo.js` at the point of use
  rather than papered over.

  🔑 **Why the te reo could not follow, checked rather than assumed.** There is
  **no attested abstract noun for "dining"** in te reo. Every dictionary result
  is a **place**: `wharekai` (dining hall), `taiwhanga kai` (dining area),
  `rūma kai` (dining room), `paparahua` (dining table). A *place* word on a
  control that picks takeaway from dine-in is **the exact fault 37j fixed** when
  it removed *"Ngā wāhi katoa"* — so adopting one would re-introduce a bug this
  repo has already paid to remove. The obvious head noun `kai` means **food**,
  which collides with the cuisine select's `Ngā momo kai katoa` two controls
  away.

  🛑 **And composing one is barred here.** `reo.js`'s SAFETY BOUNDARY forbids
  inventing a term without a fluent speaker. The neighbouring drafts in that file
  (`Ngā tāera kai katoa`, `Momo kai`) are compositions in **patterns the file
  already uses over nouns it already carries**; there is no such pattern or noun
  for this sense, so the same move is not available.

  🎯 **Three ways out. None is a session's call, and the middle one is a real
  cost, not a free option.**
  1. **A fluent speaker supplies a phrase** for *how a meal is taken* — the only
     route that ends with both halves right.
  2. **Drop the gloss** so the control falls back to English. Honest, immediate,
     and a genuine regression in reo coverage on a control that had it.
  3. **Reconsider the English.** "Dining" is the owner's word, ruled after
     "Service" and "Order type"; a word with an attested te reo noun behind it
     would make this go away. Raising it is fair; overruling it is not.

  🚩 **A second concern was raised with him and his wording stands, recorded so
  nobody re-opens it by reflex:** the `style` select beside this one is *"a style
  of **dining** filter"* (37k — quick eats through fine dining), so two adjacent
  controls now touch the same word.

  📌 **Until it moves, leave the gloss exactly as it is.** A wrong gloss that is
  visibly recorded as wrong beats a right-looking one that was guessed — and the
  record is what stops the next session "tidying" it into an invention.
